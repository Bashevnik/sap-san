# SAP SAN — Resort &amp; Retreat

Статичний сайт бази відпочинку SAP SAN (Бакали, Київська обл.).
Без збірки й фреймворків: HTML + CSS + ванільний JS. Node потрібен
лише для інструментів у `tools/` (обробка фото, шрифти, фірмова
графіка) і локального сервера.

```bash
npm install        # sharp + potrace, тільки для tools/
npm run serve      # http://localhost:4173
```

### Порядок підключення скриптів

Порядок важливий, він однаковий на всіх сторінках:

```

config.js                          apiBase адмінки
images.js                          маніфест кадрів (генерується)

```

## Фото

**Єдине джерело — `new-images/`.** Каталог `images/` збирається
повністю автоматично й може бути видалений і відновлений.

```bash
node tools/build-images.js              # усі кадри
node tools/build-images.js lake-aframe  # один слаг
```

Для кожного кадру пишеться сходинка ширин у **AVIF + WebP**, а де
потрібно — ще й вертикальне (3:4) та квадратне обрізання **навколо
точки інтересу**, а не по центру. Каталог кадрів (слаг, роль, фокус,
тон, alt) лежить у `tools/build-images.js` — правити треба саме там.

У розмітці шляхи руками не пишуть: усе йде через
`SAPSAN.picture(slug, opts)`, який сам збирає `<picture>` з обома
форматами, `sizes`, розмірами (проти CLS) і `--fx/--fy`.

> **Batch_4:** у цій партії імена файлів зсунуті — починаючи з `04_*`,
> файл N містить кадр, описаний іменем N−1. Мапінг у каталозі
> зроблено за фактичним вмістом. Не «виправляйте» його під імена.

## Фірмова графіка

```bash
node tools/brand-svg.js
```

* **Сокіл** обведений з реального логотипа SAP SAN
  (`new-images/…/03_brand_banner.png`): кадр бінаризовано за Otsu,
  залишено дві найбільші компоненти, обведено potrace. Шлях лежить у
  `tools/falcon-path.json` і потрапляє і в `assets/brand/falcon.svg`,
  і в `js/falcon.js` — одне джерело на весь сайт.
* **Верба, сосна, очерет, вода** генеруються процедурно з
  детермінованим PRNG, тому повторний запуск дає ті самі файли.
* Декор підключається як `mask-image` (`.decor--willow` тощо), тому
  фарбується в `currentColor` поверхні й лишається різким.

## Шрифти

```bash
node tools/build-fonts.js
```

Тягне з Google Fonts тільки потрібні підмножини (latin, latin-ext,
cyrillic, cyrillic-ext) і пише `assets/fonts/fonts.css` з локальними

Jost — геометричний гротеск для інтерфейсу.

## Контент і адмінка

Увесь текст живе в `js/data.js`. Якщо в `js/config.js` заданий
`apiBase`, сайт тягне `GET {apiBase}/content` і підміняє ним
вбудований контент.

**Відповідь API проходить перевірку** (`sanitize()` у `data.js`).
Телефон, пошта, посилання, координати, час, ціни й слаги фото
мають однозначну форму — усе, що її не має, відкидається, і на
місці лишається вбудоване значення. Списки приймаються за
принципом «усе або нічого»: частковий прайс гірший за неоновлений.
Кожне відкинуте поле пишеться в консоль:

```
[SAP SAN] дані з адмінки не пройшли перевірку і замінені вбудованими: …
```

> ⚠️ Станом на зараз в адмінці лежать тестові значення (телефон
> `1312312`, адреса `LDLSLFLSLFSLF`, ціна квитка 21 121 323 115 154).
> Сайт їх не показує, але поки їх не замінять реальними, контент
> береться з `data.js`.

Заявки йдуть на `POST {apiBase}/bookings` (`js/booking.js`).
Формат payload — в `API.md`.

## Слайдер будиночків

`js/curtain.js` — **не карусель**. Кожна панель це рухоме «вікно» у
фотографію, яка лишається нерухомою в координатах сцени: при drag
кадри перетікають один крізь одного, бічний неперервно заходить на
місце центрального. `drag` керує `progress ∈ [-1, 1]` напряму;
відпускання до 50 % повертає назад, після — доводить.

Механіку міняти не можна. Безпечно правити тільки фото, плавність
доводки й обробку вказівника.

## Рух

`js/motion.js`. GSAP + ScrollTrigger — усе, що прив'язане до
контенту; lax.js — повільний дрейф декору. Гачки в розмітці:

| атрибут / клас | що робить |
|---|---|
| `[data-split]` | заголовок виїжджає рядками з-під маски |
| `[data-reveal]` | блок тексту; значення = затримка в секундах |
| `.reveal-img` | кадр відкривається горизонтальною шторою |
| `.par` + `[data-par]` | глибина: зсув усередині власної рамки |
| `[data-lax]` | дрейф декору: `slow` / `drop` / `sway` |

`prefers-reduced-motion` вимикає все, лишаючи статичний вигляд.
