# SAP SAN — Resort & Retreat

Багатосторінковий сайт бази відпочинку. HTML + CSS + vanilla JS.
Без збірки й фреймворків — вантажиться з будь-якого статичного хостингу
(Vercel, Netlify, nginx).

Локально:

```bash
npx http-server -p 8911 -c-1
```

---

## Сторінки

| Файл | Що це |
|---|---|
| `index.html` | Головна: hero, про базу, переваги, напрямки, слайдер будиночків, басейн, історія дня, кухня, галерея, FAQ, карта, CTA |
| `houses.html` | Усі будиночки — картки з цінами й кнопкою заявки |
| `house.html?id=…` | Сторінка будиночка: фото, опис, зручності, гості, ціни, правила заїзду |
| `pool.html` | Басейн: години, прайс дорослі/діти, шезлонги, правила, галерея |
| `gallery.html` | Фотогалерея з фільтром за категоріями та лайтбоксом |
| `rules.html` | Правила та FAQ: оплата, скасування, заїзд/виїзд, діти, тварини, басейн |
| `contacts.html` | Google-карта з міткою, «Прокласти маршрут», усі контакти |
| `booking.html` | Дві форми заявок: будиночок і шезлонги |

Сторінка будиночка одна на всіх — картка обирається через `?id=`.
Додали будиночок у `data.js` — сторінка зʼявилась сама.

## Підключення бекенду й Telegram-бота

**Повний контракт API — у [API.md](API.md).**
**Промпт для розробника бота — у [BOT_PROMPT.md](BOT_PROMPT.md).**

Єдиний файл, який редагує бекендер, — `js/config.js`:

```js
window.SAPSAN_CONFIG = { apiBase: 'https://бекенд.vercel.app/api' };
```

Порожній `apiBase` = сайт працює на вбудованому контенті.


### 1. Контент — `js/data.js`

```js
load() { return fetch('/api/content').then(r => r.json()); }
```

Форма відповіді має збігатися з обʼєктом `data`: `settings`, `advantages`,
`houses`, `housePricing`, `pool`, `experiences`, `chapters`, `gallery`,
`galleryTags`, `faqGroups`.

### 2. Заявки — `js/booking.js`, функція `submitBooking(payload)`

```js
return fetch('/api/bookings', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(payload)
}).then(r => { if (!r.ok) throw new Error('failed'); return r.json(); });
```

**Payload — будиночок:**

```json
{
  "type": "house", "source": "website", "createdAt": "2026-08-12T10:00:00.000Z",
  "checkin": "2026-09-10", "checkout": "2026-09-13", "house": "aframe-pano",
  "adults": "2", "children": "0", "name": "Олена", "phone": "+380 67 111 22 33",
  "comment": "…",
  "summary": "🏠 Заявка на будиночок\nЗаїзд: … · Виїзд: …\nБудиночок: …\nГостей: …\nІмʼя: …\nТелефон: …"
}
```

**Payload — шезлонги:** те саме, але `type: "sunbeds"`, `date`, `sunbeds`
замість дат і будиночка.

Поле **`summary`** — уже готовий текст для повідомлення адміністратору
в Telegram: тип заявки, дати, будиночок або кількість шезлонгів, імʼя,
телефон, гості, коментар. Достатньо переслати його як є.

### 3. Захист від спаму

На фронтенді вже стоїть три рівні: honeypot-поле `company`, мінімальний
час заповнення 3 с і обмеження частоти 30 с. **Серверну перевірку робить
бекенд** — payload приходить уже без поля `company`, тож на боці API
варто додати свій rate-limit за IP.

### 4. Адмінпанель

Усе, що працівники мають редагувати самі (будиночки, ціни, фото, прайс
басейну, посилання на меню, контакти, правила, години), лежить у
`js/data.js` пласкою структурою — її можна один-в-один віддзеркалити
в БД і віддавати через `/api/content`.

## ⚠️ Що ще треба від замовника

Ці місця навмисно не заповнені вигаданими даними.

| Де | Що |
|---|---|
| `data.js` → `housePricing.holiday.price` | Святковий тариф. Поки `null` — сайт пише «за запитом» |
| `data.js` → `pool.children[1].price` | Тариф для дітей від 5 років |
| `data.js` → `houses[].name`, `area` | Реальні назви будиночків і площа |
| `data.js` → `pool.rules` | Повний офіційний перелік правил басейну |
| `faqGroups` → скасування, тварини | Зараз чесне «уточнюйте за телефоном» замість вигаданої політики |
| Усі сторінки | Замінити домен `sapsan-resort.com.ua` у canonical, OG, `sitemap.xml`, `robots.txt` |

Кількість будиночків у коді — три. Якщо їх інша кількість, просто
відредагуйте масив `houses` — слайдер, сторінки й форма підлаштуються.

## Зображення

`images/` — оптимізовані WebP у трьох ширинах (640 / 1000 / нативна).
Імена містять реальну ширину, тому `srcset` не обманює браузер.

Перегенерація після додавання фото:

```bash
npm i sharp
node tools/optimize.js
```

Карта «оригінал → назва» задається у скрипті вручну: підбір кадрів
навмисно ручний.

## Доступність і стійкість

- `prefers-reduced-motion` — анімації вимикаються
- без GSAP (CDN недоступний) — весь контент лишається видимим
- без JS — видно текст, ціни й контакти
- контраст дрібного тексту ≥ 4.5:1 на всіх поверхнях
- меню й лайтбокс закриваються по Esc, керуються з клавіатури
